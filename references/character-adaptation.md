# 通用角色替换与动作适配

仅在本次任务明确选择替换主角后启用；不预设任何固定角色。

## 参考依据

查看用户实际提供的角色参考图及已确认的文字设定。角色图控制外观和身体结构，原视频控制动作时序及镜头意图，背景和物品参考只控制用户指定的内容。材料缺失时请用户提供，不凭角色名字假装已经知道精确外观。

记录可见外观、颜色、身体比例、肢体与手指结构及标志性特征；遮挡或不确定的细节不猜测。多角色建立稳定的一对一映射，仅替换指定目标，保持其他角色身份与互动关系。

## 动作迁移

保留原动作顺序、节奏、方向、关键姿态意图、镜头切换与互动关系。根据目标角色的身体结构调整步幅、动作幅度、重心、支撑点、接触高度和道具尺度。例如短四肢角色可以通过较低桌面、较小道具和适当机位完成动作，不应为复制人体动作而拉长肢体或增加手指。

必要变化在适配说明中列出，不宣称动作完全相同。不能把原主角的条纹、尾巴、衣服或其他独有结构自动转移到新角色；服装和道具迁移以用户选择为准。

保持镜头方向、速度变化、切镜时机与构图意图。因角色尺寸差异调整机位高度或距离时，记录改变。首帧起始姿态与目标视频提示词匹配，给后续动作留出空间。

## 声音与表达

依用户已确认的语言与声音设定处理台词。角色不具备说原语言的设定时，不默认照搬口型或对白；根据任务需要提出动作表达、用户指定配音或翻译字幕等选择，未确认的方案不写成既定目标。必要时询问，同时完成不依赖声音选择的视觉分析。

## 一致性与输出

所有中英文目标视频提示词、生图提示词及 HTML 都使用同一目标角色版本，保持编号、参考作用及动作要求一致。附必要的适配说明，不把修改后的画面写成原视频事实。每段自足；仅凭名称不能准确识别的角色应给出足够外观描述或明确真实参考素材。
